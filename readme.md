# BrakeGuard-MYOSA

Continuous IoT-based capacitive brake fluid moisture health monitoring system using the MYOSA Mini IoT Kit.

## About

BrakeGuard is a low-cost embedded safety system that monitors brake fluid moisture and braking conditions to identify brake-fluid degradation and provide an early indication of brake fade risk.

## MYOSA Blog Submission

Read the full project blog: [brakeguard-myosa.md](brakeguard-myosa.md)

## Tech Stack

- ESP32 (MYOSA Mini Kit)
- MPU6050 Accelerometer/Gyroscope
- BMP180 Barometric Sensor
- OLED Display
- MQTT Protocol
